# emdedded-system-lab-project
# Traffic Light System

## Task 1: Traffic Light

Single-lane traffic light (`RED`, `YELLOW`, `GREEN`) controlled by an Arduino using a `switch-case` state machine and timing events.


## Task 2: Pedestrian Crossing Extension

Extends the car traffic light system with a pedestrian light (`RED`, `GREEN`) and push-button request using a `switch-case` state machine.

---

## Task 3: Hardware Realization (Real Arduino)

Maps the Task 1 class diagram, state machine, and simulation onto a physical Arduino Uno and breadboard circuit, verified with hardware testing and structured Git version control.



## Task 4: Pedestrian System Hardware Realization & Interrupts

Maps the Task 2 pedestrian crossing system onto a real Arduino Uno and compares polling-based vs. interrupt-based (`ISR`) push-button detection.
